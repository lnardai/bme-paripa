# BME PARIPA — Cloudera research topic

Slides for the **PARIPA** (Partnership with Industry) topic announcement at BME:
*Trustworthy AI for autonomous cluster diagnosis.*

**Published deck:** https://lnardai.github.io/bme-paripa/

An LLM-based agent investigates a Cloudera data cluster that has failed, reading the
real machines to find out why. The open research question is not whether it can do
that — it can — but which safety guarantees can be made to hold whether or not the
language model is correct, secure or obedient.
